# Script Library

- `source/` contains the editable Excel workbook (`script-library.xlsx`).
- `source-sets/` contains the generated runtime JSON files.
- `index.json` will later be generated by the importer.
- The runtime never reads Excel directly.

Run `npm run scripts:import` to validate the workbook and regenerate the Source Set JSON files and lightweight index. The Script Library is not connected to generation yet.
